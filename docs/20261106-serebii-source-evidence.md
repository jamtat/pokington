The shared approved wreq Chrome147/macOS client now follows at most five redirects. The diagnostic Serebii runner validates the final origin, caps bodies at 4 MiB, preserves original response bytes, and decodes the source's declared ISO-8859-1 text.

## Unresolved coverage and metadata

Its explicit [Gen IX link](https://www.serebii.net/pokedex-sv/tauros/) provides Normal, Paldean, Blaze Breed (fighting/fire), and Aqua Breed (fighting/water). The parser preserves these source groups; it does not silently inherit fighting alone for all three breeds. Full-catalogue alias matching remains unimplemented.
- [Unown hub](https://www.serebii.net/pokemon/unown/) exposes one PNG artwork reference. Its linked [Gen VIII page](https://www.serebii.net/pokedex-swsh/unown/) also exposes one species image and links to [Legends: Arceus Unown locations](https://www.serebii.net/legendsarceus/unownlocations.shtml). That page explicitly lists 28 named Unown forms, illustrated by JPG gameplay/map screenshots. Three other actual hub-linked pages ([Gen VII](https://www.serebii.net/pokedex-sm/201.shtml), [Gen VI](https://www.serebii.net/pokedex-xy/201.shtml), [Gen V](https://www.serebii.net/pokedex-bw/201.shtml)) also supplied only one standard species image each. This bounded investigation has not found a complete source-linked PNG artwork set; it does not prove that no such file exists anywhere on Serebii. No suffix guesses were made.
- [Alcremie hub](https://www.serebii.net/pokemon/alcremie/) exposes only original and Gigantamax artwork. Its explicit [Gen IX page](https://www.serebii.net/pokedex-sv/alcremie/) exposes additional sweet variants as game-render PNGs and flavour-specific icons. One actual Berry Sweet render is 250×250 RGBA, compared with 475×475 or 570×570 for the hub artwork samples below. Game renders have not been silently adopted as equivalent full artwork, and the full sweet/flavour product has not been inferred or enumerated.
- Duplicate source labels remain in the raw artwork inventory: Pichu has two “Spiky-eared Pichu” references, Urshifu has two “Gigantamax Urshifu” references, and Ogerpon has two “Ogerpon wearing Teal Mask” references. Other semantic duplicates use different labels/URLs, for example Castform's original image and its separate Normal panel. Source references therefore need canonical identity reconciliation before descriptive form keys or final form totals can pass. No numeric disambiguation names have been invented.
- These are concrete source/artwork integration gaps, not HTTP-access failures. Complete cross-generation form coverage remains open; the hub crawl alone does not establish it. No source is adopted by the executable, which remains the original scaffold.

## Prototype and checks

- `src/serebii.rs`: source-derived index bounds/links; profile artwork and source-script selector inventory; explicit type-group evidence with source labels. It deliberately does not return an accepted canonical species/form catalogue.
- `examples/discover_serebii.rs`: bounded live crawl or offline replay, preserving response bodies and reporting parsing errors separately from transport failures. Output filenames say inventory rather than catalogue.
- `examples/inspect_png.rs`: independent offline full PNG/checksum/transparency validation. Existing official/regional prototypes remain historical, unadopted code until a complete replacement is established; they are not runtime fallbacks.
- `tests/serebii.rs` and six reduced HTML fixtures: dynamic advertised bounds, missing/duplicate/malformed index rejection, anti-bot/truncated documents, actual Mega/Gigantamax and named Tauros breed references, missing original artwork, wrong species identity, non-PNG format drift, unknown type rejection, explicit breed type evidence, and the known one-image Unown hub limitation.

One interim rebuild also warned that a zstd object was built for a newer macOS version than the link deployment target. Executables linked and all checks exited successfully; these warnings were not hidden or fixed, and Linux/native portability is not established by this macOS run.
